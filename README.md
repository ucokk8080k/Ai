# AIBot (Spigot/Paper 1.8 - 1.21+)
Build: `mvn clean package` -> target/AIBot-1.0.0.jar (Java 8+ untuk build)
Install: taruh jar + ProtocolLib 5.x di folder plugins/, restart. Edit plugins/AIBot/config.yml.
AI chat (opsional): ai.enabled: true + isi ai.api-key (atau env AIBOT_API_KEY).
Perintah: /aibot list|count|reload|join <nama>|leave <nama>|say <nama> <pesan>  (perm: aibot.admin)
